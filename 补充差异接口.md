# 补充差异接口

| 接口                | 额外需求                         | 注   |
| ------------------- | -------------------------------- | ---- |
| GET `/post/replies` | 添加回复人的用户名`author`       | 补充 |
| GET `/posts`        | 添加帖子所属的贴吧名`forum_name` | 补充 |
| GET `/post/detail`  | 添加帖子所属的贴吧名`forum_name` | 补充 |
| POST `/user_login`  | 添加用户信息`username`和`bio`    | 补充 |

- GET `/post/replies?post_id=&page=&limit=&sort=&uid=&token=`

  - ```json
    {
      "error": 0,
      "replies": [
        {
          "reply_id": 1, "post_id": 4, "uid": 1054, "content": "...",
          "parent_reply_id": 0, "floor": 1, "like_count": 0, "created_at": "...",
          "is_liked": false,
           "author":"张三",//与uid对应
          "sub_replies": [
            {
              "reply_id": 2, "post_id": 4, "uid": 1054, "content": "...",
              "parent_reply_id": 1, "root_reply_id": 1, "floor": 0,
              "like_count": 0, "created_at": "...", "is_liked": false
                ...//同理
            }
          ]
        }
      ]
    }
    ```

- `GET /posts?forum_id=&page=&limit=&sort=`  

  - ```json
    { "error":0, "posts":[
    {"post_id","forum_id","uid","author","title","created_at","reply_count","like_count","is_top",
    "is_essence","content_preview"，
    “forum_name" // 与forum_id对应
    } ] }
    ```

- GET `/post/detail`

  - 同上

- POST `/user_login`

  - ```json
    {"email","error","host","port","token","uid",
    "username","bio",//用户信息添加
    }
    ```
